# Garimpo Smart

Projeto com dicas para casa, recomendações de produtos e uma área para revisar resultados de pesquisas.

- [Blog](https://wesleyttiago.github.io/garimpo-smart-ml/blog/)
- [Curadoria](https://wesleyttiago.github.io/garimpo-smart-ml/)

## Rodar no computador

Com Python instalado, na pasta do projeto:

```bash
python3 -m http.server 8000
```

Abra http://localhost:8000/blog/ para o blog ou http://localhost:8000 para a curadoria.

As instruções das automações estão em [automation](automation/README.md) e [pesquisa de anúncios](automacoes/pesquisa-anuncios/README.md). A atualização do blog está em [blog](blog/README.md).
