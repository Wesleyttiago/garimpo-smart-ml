# Casa & rotina

Blog do Garimpo Smart com dicas para casa e recomendações de produtos, feito com HTML, CSS e JavaScript.

[Ver o blog](https://wesleyttiago.github.io/garimpo-smart-ml/blog/)

## Atualizar

Edite os guias em `content.json` e `more-content.json`. Os produtos ficam em `products.json` e `research-products.json`.

Na raiz do repositório, com Node.js instalado:

```bash
node blog/build.mjs
```

Para conferir no computador, com Python instalado:

```bash
python3 -m http.server 8000
```

Abra http://localhost:8000/blog/.

Alguns produtos ainda estão em curadoria. Confira os anúncios e links antes de publicar. Mais detalhes em [CURADORIA.md](CURADORIA.md) e [PRIMEIRO-TESTE.md](PRIMEIRO-TESTE.md).
